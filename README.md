# Odin Recipes

A simple HTML only website about cooking recipes as an intro project to learn the basics of HTML.

## Description

[Odin Recipes](https://www.theodinproject.com/lessons/foundations-recipes) is a project in the foundation portion of the [Odin Project](https://www.theodinproject.com/paths)
design to give learners an opportunity to do hands-on HTML development. The project is comprised of a home page with 3 links to separate recipe web pages. In the recipe web pages, you will find a home button, an image of the food created from the recipe, ingredients, and steps to make the recipe.

## Visiting Website

Thanks to **GitHub Pages**, deployment of the project is made easy and you can easily access the developed website [here](https://acostabsu.github.io/odin-recipes/)
